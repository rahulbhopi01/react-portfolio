# React Portfolio

## Overview
This is a personal portfolio website developed using React and Vite. It showcases my skills, projects, resume, and contact information.

## Features
- About Me
- Skills
- Projects
- Resume
- Contact
- Responsive Design
- React.lazy()
- Suspense

## Technologies Used
- React
- Vite
- JavaScript
- CSS
- Git
- GitHub
- Vercel

## Development
To run the project locally:

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment
The project is deployed on Vercel.
